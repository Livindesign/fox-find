# Support Fox Find / 支持 Fox Find

**Sponsorship is not enabled yet. / 收款入口暂未启用。**

Fox Find is free to use and its source is MIT-licensed. You do not need to pay
to enable OCR, document search or the experimental local semantic features.
Their technical prerequisites still apply.

We plan to add a verified **Afdian (爱发电)** link after the maintainer sets it up.
There is no payment URL or QR code to use right now. Do not pay anyone claiming
that a contribution is required to activate this build.

Any future voluntary support will fund Fox Find maintenance, compatibility testing
and documentation. It supports **Livindesign's independent fork**, not Oil Find,
DigUp or llama.cpp. It does not promise a delivery date, priority support,
exclusive features, a tax-deductible donation or an upstream product license.
The applicable platform payment/refund rules will be linked when funding opens.

You can help today by reporting a reproducible issue, checking an older macOS
version, translating the interface or sharing your experience. If you find the
project useful after trying it, a star helps people discover it.

也欢迎直接支持 [Oil Find](https://github.com/oil-oil/oil-find)、
[DigUp](https://github.com/ARahim3/DigUp) 和 [llama.cpp](https://github.com/ggml-org/llama.cpp)。
我们保留原作者的版权和许可，感谢他们提供的基础。

后续赞助始终自愿，不解锁功能、不改变 MIT 许可、不代表原项目背书。
目前没有开启 GitHub Sponsors，也没有配置 `.github/FUNDING.yml`；确认真实收款地址后才启用。
