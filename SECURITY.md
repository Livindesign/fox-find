# Security

Only the current preview is being maintained. There is no guaranteed response
time or paid security support agreement.

For a security problem, use the repository's **Security → Report a vulnerability**
entry when available. Do not open a public issue with private documents, index
contents, credentials, or an exploit that exposes another user's data.

If private reporting is unavailable, open a generic issue asking the maintainer
for a confidential channel, without technical or personal details.

The local content database stores plaintext; see [privacy](PRIVACY.md). Preview
builds are ad-hoc signed and not notarized. Download only from this repository's
release page and check its published SHA-256. Checksums do not establish Apple
notarization or protect against a compromised maintainer account.
