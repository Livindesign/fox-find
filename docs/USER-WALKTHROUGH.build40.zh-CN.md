# Fox Find build 40 · 本轮体验清单

适用版本：0.0.1 build 40，完整本地候选版。使用 `/Applications/Fox Find.app`，不是 Workflow Preview。上一版的完整走查清单仍适用；下面只补充本轮变化，复选框留给用户亲手验收。

## 收集篮有什么用

例如你要整理一次产品拍摄：先搜到原图，加入收集篮；换一次搜索找说明文档，也加入；再从 AI 对话里选一段要求，加入摘录。搜索词变了，之前收集的内容仍在。

- **复制文件**：复制所收集文件的引用，可粘贴到 Finder 等支持文件粘贴的位置。
- **导出副本**：把这些文件复制到新目录，原文件保留。
- **复制清单与摘录**：复制文件路径、选中的对话文字和你填写的下一步；不自动读取文件正文、不自动发给 AI。
- **保存 Markdown**：把上述清单保存成文本文件。给 AI 阅读原文件时，还需在目标工具里附加原文件或授予它访问能力。

## 这次重点检查

- [ ] 搜到一个测试文件，按 `⌘⇧C`。预期：加入收集篮，仍停在搜索；再加同一个文件不重复。
- [ ] 改搜索词再收集第二个文件，按 `⌘⇧B`。预期：收集篮可靠出现，两个文件都保留。
- [ ] 关闭收集篮。预期：回到原搜索词和结果，不跳到其他窗口。
- [ ] 再次打开收集篮，唤回搜索，选中图片按 `⌘Y`，再按空格关闭预览。预期：返回搜索，不重新出现收集篮。对 PDF、文本和对话预览也分别检查关闭返回。
- [ ] 收集篮底部只有一行提示。点击“复制清单与摘录”后，同一位置变成“已复制清单与摘录”；不会又多出一行。`⌘Return` 执行相同操作。
- [ ] 在收集篮按 `⌘S`。预期：打开 Markdown 保存对话框；取消后留在收集篮。
- [ ] 菜单打开时，移动到菜单各项。预期：只有菜单跟随鼠标高亮，下面的列表不串 hover；点击菜单外关闭后列表恢复响应。
- [ ] 检查筛选、查找方式、更多操作和右键菜单。预期：操作条目统一为图标加文字，不出现一部分有图标、一部分只有文字。
- [ ] 遇到部分文件失败或无权限的状态。预期：主说明及主操作集中显示，权限提示作为次要一行，不铺满窗口。

本轮验证范围是窗口返回、菜单反馈和上述界面变化，不代表全产品发布验收完成。全量清单见 [build 39 功能走查](USER-WALKTHROUGH.build39.zh-CN.md)。
