# Roadmap

This is a direction, not a delivery-date promise. Stability and complete behavior
take priority over adding more controls.

## Before a broad public launch

- Cross-Mac acceptance, including the oldest supported macOS and large real folders.
- Developer ID signing and Apple notarization for a smoother install path.
- Repeat real-world filename/OCR/PDF/photo scenarios and measure scrolling under indexing load.
- Add maintainer-confirmed Afdian funding URL; check wording and payment terms.
- Explicit maintainer approval to change repository visibility and enable the website.

## Next usability work

- A first-run content-folder setup with a real-file example that explains index coverage.
- Clear progress and missing-permission feedback without changing result layout.
- Improve Chinese description relevance and explain why a semantic result is shown.
- Broader accessible keyboard and VoiceOver testing.

No subscription, sponsored search placement or mandatory donation is planned for this preview.
