# 开始使用

Fox Find 提供原生使用引导，可在菜单栏或设置中选择「使用引导…」重新查看。详见 [引导说明](ONBOARDING.md)。

## 找文件名或应用

打开 Fox Find，按 **⌘⇧L**，输入名称。**Return** 打开，**⌘Return** 在 Finder
中显示，**⌘Y** 快速预览。「应用」分类可以缩小到应用程序。全局快捷键可在设置修改。

「查找方式」控制匹配范围：「自动」组合可用来源，「仅文件名」只找名称，
「文件内容」找已经提取的文字。它不是排序；名称、日期、大小、相关度在「排序」中选择。
清空输入会清空本次匹配结果。

## 找文档或图片里的文字

1. 设置 → 内容搜索，添加一个你熟悉的文件夹。
2. 系统询问目录权限时允许，等待索引文件数量增加。
3. 输入其中某张图片或某份 PDF 中确实存在、有辨识度的词。
4. 选中结果，右键或按 **⌘K** 查看可用操作。

允许系统目录权限，不等于把它加入内容搜索。未添加的目录不会产生内容匹配。

## 描述搜索与找相似图片（实验功能）

1. 添加包含图片或文档的内容文件夹。
2. 在设置开启「本地语义搜索 · 实验功能」。
3. 点「下载本地模型」（约 865 MB），等待校验完成，并出现已索引的语义片段数量。
4. 在「自动」或「文件内容」输入一个描述，内容应确实在所选文件夹中。候选会标注
   「可能相关」，需自行预览核对。
5. 对本机可读的一张图片点右键 →「找相似图片」；也可以在搜索工具栏的更多菜单中
   选择外部参考图片。
6. 修改/清空输入，或点参考图片旁的退出控件，结束相似搜索。

这里的图片应是 Mac 本地文件或已连接硬盘上的文件，不是网页图片 URL。
结果受目录覆盖、索引进度和模型相关性影响，不能保证每个描述都能命中。

## 找回 AI 对话

1. 设置 →「AI 对话」，开启本地对话搜索，再选择 Codex、Claude Code 或 WorkBuddy。
2. 回到主窗口，选择「AI 对话」分类，输入标题或聊天正文中的关键词。例如「包装 蓝色」会要求两个词都出现。
3. 选中结果按 **Return**，支持桌面跳转的会话会在原应用中打开。只有 CLI 记录的会话可从 **⌘K** 菜单复制继续会话命令，自行在终端运行。
4. **⌘Y** 查看本地对话文字，**⌘K → 复制对话内容** 复制含来源的 Markdown。选中结果后也可按空格查看。
5. 清空输入立即清空结果；输入 `*` 查看最近会话。未出现的分类可在分类栏「…」中找到。

默认不启用，不需要模型下载。索引仅涵盖这台 Mac 上的本地记录，不包含所有 ChatGPT/Claude 网页聊天。
对话不混入文件结果，文件的类型、位置和日期条件仍独立生效。
部分客户端不提供精确消息跳转，打开的是会话；本地文字窗口会选中首个关键词。
较长对话的预览/复制有大小限制，会明确提示截断。关闭来源后不可再查看其缓存内容；设置中的清除按钮只删除 Fox Find 副本。

## 查看 PDF 中的相关内容

只有结果明确标注页码时，才能跳到该页。选中后按 **⌘⇧Y**，或在文件操作菜单中打开
相关页面。页码是 PDF 的物理页，可能与正文印刷页码不同。打开前会核对文件指纹；
文件改动后需要重新搜索。普通 PDF 结果的同一快捷键可能用于查看已识别文字。

## 跨多次搜索整理材料

收集篮是一份项目临时清单。例如，先找需求文档，再找参考图，最后摘录一段 AI 对话，
把几次搜索的结果留在一起。

1. 选中文件按 **⌘⇧C**，或在操作菜单选择「加入收集篮」。
2. 继续找其他材料，按 **⌘⇧B** 查看已收集的文件和摘录。
3. 填写标题与交接说明，移除不需要的项目，再复制清单（**⌘Return**）或保存（**⌘S**）。
4. 其他软件或 AI 需要读取全文时，另行附上原文件。

导出的是路径和所选摘录，不包含文件全文或打包附件。移除清单项目不会删除原文件，
也不会影响收藏。图片的「比较原文件候选」展示候选及可用的尺寸、大小依据，
不判定原创归属，也不覆盖文件。

## 没有结果时

先检查分类、位置、日期和查找方式；移除条件标签，或清空筛选。内容搜索需要确认目录已添加、
权限已允许、索引未暂停、文件已下载且可读取。按「拍摄时间」找照片，需要相应元数据，
不等同于文件修改日期。语义搜索还需确认模型和语义片段数量；可以先搜文件名排除索引范围问题。

## 卸载

退出 Fox Find，将「应用程序」中的 **Fox Find.app** 移到废纸篓。索引默认保留；
需要清理时，单独删除 `~/Library/Application Support/Local Find/`。这是本分支的数据目录，
删除的是索引、缓存和离线目录，不是原始文档。本仓库不提供会操作 Oil Find 的安装/卸载脚本。
