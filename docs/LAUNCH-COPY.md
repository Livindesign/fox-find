## English

**Fox Find: native Mac search for filenames, documents and screenshot text**

I’m working on Fox Find, an independently maintained MIT derivative of Oil Find's
public core. It adds local OCR/document indexing, a simpler file-action workflow
and optional experimental semantic/image-similarity search, with selected runtime
components adapted from DigUp.

The preview is free, Apple-silicon only and not yet Apple-notarized. Content search
needs folders you explicitly add; semantic search also needs a separate model.
I'd especially value feedback on first-run setup, search stability and older macOS versions.

Source and preview: https://github.com/Livindesign/fox-find

## 中文

**我做了个 Mac 搜索工具：除了文件名，也能找截图里的字**

Fox Find 基于 Oil Find 的 MIT 开源核心独立维护，补充了本地 OCR、文档内容索引、
文件操作菜单，以及可选的实验性语义/相似图片搜索。部分语义运行时改编自 DigUp，
原作者的版权、许可和来源都保留在项目里。

先添加一个熟悉的文件夹，等内容索引建立后，试着搜截图或 PDF 中的一句话。
目前是 Apple 芯片预览版，还没有 Apple 公证，也没完成更多 Mac 的兼容测试。
想找一些愿意试用并反馈安装、搜索稳定性和索引体验的朋友。

项目与预览下载：https://github.com/Livindesign/fox-find
