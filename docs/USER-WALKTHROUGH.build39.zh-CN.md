# Fox Find build 39 · 用户体验与功能走查清单

适用版本：**0.0.1 build 39，完整本地候选版**。安装位置：`/Applications/Fox Find.app`。

这份清单用于你亲手验收，所有勾选默认留空。它描述应该达到的体验，不表示这些项目已经全部通过。

## 先认清当前版本

| 版本 | 包含什么 | 当前用途 |
| --- | --- | --- |
| build 37 | 之前的完整搜索应用及修复 | 已备份，作为回退版本 |
| build 38 / Workflow Preview | 六个虚构条目的独立二期演示包 | 只用于演示；不要用它验收真实搜索 |
| **build 39 / Fox Find** | 原有功能 + 收集篮、对话摘录与继续资料、原文件候选对比 + 统一中性灰界面 | **现在安装并启动的完整版本** |

本地代码已合并。公开发布尚未进行；公开更新下载安装仍需另行验收。

## 怎么使用这份清单

- 一项通过才打勾；有问题在该项后写“失败”，没有数据或条件写“未测：原因”。没有结果本身不能证明搜索正确。
- 先走 A–G 和 J–M，再走需要特殊条件的 H、I、O、Q。分段完成即可，不用持续高负载测试。
- 普通搜索用你知道确实存在的文件。先用 Finder 确认文件名、类型、大小和日期，才能判断漏搜或误搜。
- 准备一个小测试文件夹：图片、PDF、TXT/Markdown、Office 文档各一份；一个子文件夹；一个可删除的测试副本。内容搜索先只加这个目录。
- 月份测试需要真实日期依据：找几张修改时间为七月/八月的图片，以及确实带七月拍摄信息的相机照片。有不同年份样本更好。
- 原图对比准备一张原图、一份直接复制件、一张缩小导出图、一张无关图片。
- 遇到明显卡顿、彩虹球或闪退，立即停在这一项记录；不用反复重建索引、跑全盘扫描或连续重试。

反馈最简格式：`编号｜输入或操作｜实际结果｜截图/录屏（可选）`。

- [ ] **A03** 输入查询后隐藏窗口，再唤出。预期：窗口恢复可继续使用，不一直加载、无响应或意外退出。
- [ ] **A04** 点击顶部狐狸菜单。预期：图标加文字，打开搜索、设置、使用引导、检查更新、退出均能找到；开机启动为胶囊开关。

- [ ] **B01** 输入一个确实存在的完整文件名，再只输入其中一部分。预期：均能找到目标，名称和路径正确。
- [ ] **B02** 输入一个中文文件名，再试完整拼音和首字母。预期：开启拼音搜索时能命中；关闭后按设置变化。
- [ ] **B03** 输入文件编号、英文名、带空格的名称。预期：没有擅自把编号当日期；名称搜索不等待模型启动。
- [ ] **B04** 中文输入法连续输入、选词、删除、粘贴新查询。预期：输入法正常，不丢字、不串入上一次结果。
- [ ] **B05** 快速把查询 A 改为查询 B，再清空。预期：最终只呈现 B 的结果，清空后不晚到一批 A 的结果。
- [ ] **B06** 搜一个确定不存在的随机名字。预期：明确无结果，能继续编辑；不拿无关“可能相关”结果冒充精确命中。
- [ ] **B07** 搜一个应用名，选中按 Return。预期：打开对应应用；应用分类和宫格使用应用本身的图标。
- [ ] **B08** 用上下键移动、Return 打开、`⌘Return` 在 Finder 中显示。预期：操作的是当前选中的那个文件。
- [ ] **B09** 输入 `128*1.2`、`10 cm to in`。预期：分别得到 153.6、约 3.937 英寸；复制结果后可粘贴使用。

## C. 自然语言与组合条件——重点

每条输入前清除前一条筛选；检查“识别出的条件标签”和“实际文件”，两者都要正确。

| 输入 | 应该如何理解 | 验证方法 |
| --- | --- | --- |
| `八月图片` / `八月的图片` / `8月图片` | 所有年份，八月修改的图片 | 三种写法含义一致；标签说明修改时间，不强制今年 |
| `七月拍摄的照片` / `7月拍摄的图片` | 所有年份，真实拍摄日期在七月的照片 | 核对拍摄信息；不能用修改时间凑数 |
| `2025年7月拍摄的照片` | 仅 2025 年七月的拍摄日期 | 排除其他年份 |
| `7月微信图片` | 七月修改的图片，名称或路径有微信来源线索 | 不是查询微信聊天的“接收时间” |
| `7月微信图片或视频，不超过2MB` | 七月修改 + 微信名称/路径 + 图片或视频 + 大小上限 | 每个结果同时满足全部硬条件 |
| `大于10MB的PDF，不要合同` | PDF + 大于 10 MB + 排除合同关键词 | 不应混入其他类型、较小文件或被排除项 |
| `红色手串，白色背景` | 已索引素材的视觉描述，属于语义相关性 | 到 I 节验证，不能当作精确日期或名称过滤 |

- [ ] **C01** 上表第一行三种八月写法各试一次。预期：均形成图片和月份条件，不能返回只是正文提到“八月图片”的 Markdown/代码文件。
- [ ] **C02** 七月拍摄查询核对两张以上结果。预期：有跨年样本时都能命中；无拍摄日期文件不混入。
- [ ] **C03** 指定年份再去掉年份。预期：范围随标签改变，不偷偷保留前一次的年份限制。
- [ ] **C04** 执行微信组合查询。预期：条件均生效；看不到来源证据时不把它宣称为微信图片。
- [ ] **C05** 执行大小、类型和排除组合。预期：随机核对前几项，不只是第一项正确。
- [ ] **C06** 点击条件标签的 ×，再点“清除条件”。预期：结果随条件减少而更新，不出现看不见的残留条件。
- [ ] **C07** 用自然语言和手动分类/位置筛选查同一批文件。预期：可解释为同一范围，不一边命中一边漏掉。
- [ ] **C08** 输入一种未支持的复杂说法或互相冲突的条件。预期：说明未识别部分，保持可修改；不沉默丢掉条件或持续检索。
- [ ] **C09** 将一个慢的拍摄日期查询改成普通文件名。预期：旧查询可停止，普通查询及时出现，旧进度不覆盖新结果。

月份筛选无结果时，先分别核对修改时间和拍摄时间。缺拍摄元数据属于覆盖缺口；明明有符合条件的文件却不出现，记为失败。大范围拍摄日期检查若暂停或只返回部分结果，需要明确标识；这不等于“全部查完”。

## E. 列表、宫格与响应速度——重点

- [ ] **E01** 切到列表。预期：整行列表，没有右侧自动展开的大图分栏；需要预览时自己按快捷键。
- [ ] **E02** 切到宫格。预期：图片显示缩略图；文档、文件夹、应用使用对应图标，不长期停在统一灰色占位图。
- [ ] **E03** 同一批结果切换列表/宫格三次。预期：点击有及时反馈，不白屏、长时间冻结或闪退。
- [ ] **E04** 在有较多结果时上下滚动约 10–15 秒。预期：滚动连续，不卡住输入；缩略图不乱跳到别的文件。
- [ ] **E05** 观察滚动条。预期：滑块跟随滚动，停止后隐去，宽度和亮度克制，右侧内容不被裁切。
- [ ] **E06** 搜同一文件名，记录首次和第二次感受；再换一个名字。预期：旧查询不会拖住下一次，重复搜索无需重新处理整库。
- [ ] **E07** 隐藏窗口后正常使用其他软件一两分钟。预期：电脑不持续明显变慢、内存压力不持续上升。若后台确实在建索引，记录其状态，不把首次索引与空闲混为一谈。

记录卡顿时写清：文件数量大致多少、列表还是宫格、是否在后台索引、首次还是重复、卡了约几秒。无需为了“跑分”连续重试。

## F. 预览与关闭——重点

先确认设置中启用“空格预览”，再点击结果行或按向下键进入结果选择。

- [ ] **F01** 选中图片：空格打开，再空格关闭。预期：不需要鼠标点 ×，关闭后回到原选择。
- [ ] **F02** 对 PDF、普通文本、视频各重复一次。预期：系统支持的类型能预览、空格关闭；不支持的类型不让窗口卡死。
- [ ] **F03** 用 `⌘Y` 开预览、Esc 关闭。预期：快捷键一致，不误关整个应用。
- [ ] **F04** 打开预览、关闭、换下一张、再次打开。预期：内容与标题都是新文件，不出现上张图片的残影或长期空白。
- [ ] **F05** 在搜索框输入包含空格的词。预期：正在输入文字时空格用于输入，不误触发预览。
- [ ] **F06** 对有匹配页码的 PDF 使用 `⌘⇧Y`。预期：打开正确物理页；没有页码时不能假装定位到了关键词所在页。
- [ ] **F07** 打开“查看文件内容”窗口或 AI 对话文字窗口，再试 Esc、空格及关闭按钮。预期：关闭行为可理解；编辑或选择文字时不抢正常输入。

### 不同对象的菜单应怎样变化

逐行检查一次；不适用项应隐藏或禁用并解释，不应点击后才进入一条无效流程。

| 对象 | 应提供的核心操作 | 不应错误提供的操作 |
| --- | --- | --- |
| `.app` 应用 | 打开、Finder 显示、复制、收藏、收集 | 提取正文、找相似图片、比较原图；通常无需“用其他应用打开” |
| 文件夹 | 打开、进入此文件夹搜索、终端、复制/收藏 | 文本提取、比较原图 |
| 普通图片 | 预览、可用时查看识别文字、相似搜索、比较原文件候选 | 把相似度当作完全相同的证明 |
| PDF/支持的文档 | 预览、可用时查看内容或匹配页 | 图片专用比较 |
| 视频/音频/压缩包 | 打开、系统支持的预览、复制等 | 假装支持正文提取或图片相似搜索 |
| 离线文件 | 路径、已有索引信息等仍可用 | 正常启用依赖在线文件的打开/预览/复制副本 |
| AI 对话 | 查看、复制、来源支持时打开原会话、可用时复制 CLI 继续命令 | 文件的移动到废纸篓、图片比较等 |

- [ ] **G10** 按上表检查至少应用、文件夹、图片、文档、AI 对话五种对象；离线类型在 Q 节检查。

## J. AI 对话搜索与客户端跳转——重点

前提：设置中开启 AI 对话搜索并选择本机确实使用的来源。普通网页上的全部聊天不在本地搜索范围。

- [ ] **J01** 在 AI 对话分类搜索已知标题和正文关键词。预期：标题、来源、摘要对应同一条对话。
- [ ] **J02** 输入两个关键词，再输入 `*`，最后清空。预期：多词条件生效，`*` 可查看最近会话，清空不残留旧结果。
- [ ] **J03** 对 Codex、Claude 桌面可定位的本地会话、WorkBuddy 分别按 Return（仅测已安装来源）。预期：进入对应客户端的**指定会话**；只把客户端打开不算通过。
- [ ] **J04** 对同一来源，分别在客户端已打开和已退出时测试一次。预期：都能定位；不启动旧备份客户端、不复制出多个实例。
- [ ] **J05** 对只有 Claude Code CLI 记录、没有桌面会话映射的结果，检查继续命令。预期：能复制正确的继续命令并在终端恢复；不能宣称已完成桌面对话跳转。
- [ ] **J06** `⌘Y` 查看、菜单复制对话内容，粘贴到文本编辑器。预期：消息顺序、角色、来源正确；截断时明确说明。
- [ ] **J07** 在对话预览只选中一句话，点击“收集选中文字”。预期：只收集选择的部分，保留来源；到 L 节核对。

## 什么时候可以算走查完成

每个适用项目都有“通过/失败/未测”结论；三条完整任务走完；卡死、闪退、错误打开、删错/丢内容、硬条件不生效等问题必须修复后按原步骤复测。没有模型、硬盘、拍摄元数据或公开更新源的项目保留未测，不能算通过。

这份用户走查不能替代其他 Mac/macOS 版本兼容、公证分发、远程更新和大库性能的发布验证。完成本机体验后再单独决定是否发布。
