# 操作菜单可用性审计

2026-10-17。本轮覆盖右键、行内更多、⌘K、相关快捷键、搜索更多菜单、快捷结果、AI 对话与状态栏菜单。表格同时列出已修复行为及后续缺口，不能当成所有菜单在所有设备上已验收。

## 已修复的基础规则

- 文件格式支持表由 UI 与 `ContentExtractor` 共用，避免菜单声称支持而提取器拒绝。
- 应用、文件夹、压缩包、音视频、不支持的设计格式、符号链接不显示“查看文件内容”。⌘⇧Y 同样拦截，不绕过类型判断。
- 支持提取但超过 64 MB 的文件显示禁用项并说明限制；有有效 PDF 匹配页的直接查看不受文字提取限制混淆。
- 应用和普通文件夹移除“用其他应用打开”。快捷应用结果也移除该入口。
- 文件/应用的终端动作打开所在文件夹；普通文件夹打开自身，应用包不当作工作目录。
- 离线项目保留路径、名称、收藏、别名、目录索引浏览；需要源文件的操作禁用。离线文字入口明确叫“查看已索引文字”，缓存是否仍有效由后台校验后决定。
- 索引根目录不提供移到废纸篓，快捷键同样保护。禁用的动作闭包本身也不执行。
- 类型矩阵测试发现一个菜单图标可能不存在而强制解包的崩溃入口。已改用现有文件夹图标，并给未知系统图标增加占位回退。

## 状态规则与仍需补齐的动态可用性

| 状态 | 当前处理 | 待补齐项 |
| --- | --- | --- |
| 外接盘离线 | 文件操作禁用；本地索引/路径操作保留；文字缓存后台验证 | 选中时异步获取缓存状态，让“无缓存”在打开菜单前有明确禁用原因 |
| 文件删除/来源替换 | 保留菜单绑定原身份，防止误操作到别的文件；执行时再检查 | 统一“文件已移动/不存在”的行级状态，减少只发提示音 |
| 云端占位文件 | 提取器拒绝隐式下载；后台报告不可用 | 缺少“尚未下载”可用性快照；应单独给显式下载/系统打开入口 |
| 无读取权限 | 提取失败后提供原因；不自动申请整个磁盘权限 | 菜单提前展示读取状态，避免误把所有失败统称未连接 |
| 加密/损坏/无文字 | 由提取器返回具体结果，不谎报支持成功 | 缓存最近提取状态，区分“支持格式但这份文件无文字”和“格式不支持” |
| 语义模型未准备 | 找相似图动作进入设置 | 应明确显示“设置相似图片搜索”，不要用执行语气后才跳设置 |
| 快捷入口指向文件夹/失效路径 | 已修复应用包的打开方式和终端行为 | 普通自定义路径尚未共享完整的异步文件能力快照 |
| 系统 Quick Look 扩展 | 使用系统预览 | 格式可预览性取决于已安装扩展，不能用自维护白名单宣称全支持 |
| 权限/连接在菜单打开后变化 | 保留执行前检查 | 所有外部操作应复用统一的状态原因与二次校验 |

不可用性不能在右键打开的同步路径上通过逐项读盘来计算。后续 `ActionContext` 应由选中项的异步状态快照提供，执行时再次检查；菜单、⌘K、工具栏和快捷键消费同一策略。

## 其他菜单清单

| 菜单 | 条目范围 | 规则/当前缺口 |
| --- | --- | --- |
| 查找方式 | 自动、文件名、内容 | 文件名不启动语义；内容需要可用索引，缺失时说明。AI 对话使用独立索引，需要明确哪些文件过滤不适用。 |
| 类型 | 全部、文件夹、应用、文档、图片、视频、音频、代码、压缩包、AI 对话 | 类型切换不能残留冲突的自然语言条件；文件类型与“可提取文字类型”分开。 |
| 排序 | 相关度、名称、大小、修改时间 | 文件相关度与匹配方式不同；对话的相关度/时间应单独定义，不套用文件大小。 |
| 位置 | 全部、常用目录、自选、项目 | 目录离线可浏览索引；不可读目录不冒充空结果。 |
| 筛选 | 类型、拍摄时间、媒体属性、标签、尺寸、清除 | 非媒体对象的拍摄/分辨率应隐藏或标明适用范围；日期依据设计见搜索提案。 |
| 搜索库 | 文件收藏、保存搜索、历史、清空 | 保存完整 QueryPlan；清空搜索历史与删除文件严格分开。 |
| 搜索更多 | 继续元数据检查、相似图片、导出、快捷入口、内容目录 | 有暂停任务才显示继续；导出当前结果范围；AI 结果不得误导出旧文件结果。 |
| 快捷结果 | 应用、路径/URL、计算结果、单位换算 | 计算只有复制答案；URL 不显示文件删除/OCR；编辑/删除快捷入口只修改快捷入口。 |
| AI 对话 | 打开原会话、查看/复制内容、复制继续命令、来源设置 | 有有效原会话路由才展示跳转；CLI-only 记录预览/恢复命令，不能假装已打开客户端。客户端缺失提示需更提前。 |
| 状态栏 | 搜索、索引状态、权限、重建、开机启动、设置、引导、更新、退出 | 索引忙时不重复重建；更新忙时不重复检查；安装事务保护退出；信息行不可点击。 |
