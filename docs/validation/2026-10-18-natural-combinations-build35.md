# 自然语言组合检索 · 本地候选 build 35

## 已实现

这轮扩展原生搜索解析和共享查询条件，不将每个词都向量化，不增加云端调用。

| 输入示例 | 执行方式 |
| --- | --- |
| 7月微信图片 | 所有年份的七月修改时间 + 图片 + 文件名或路径含 微信 / WeChat / Weixin |
| 7月微信图片，不要红色 | 上述条件 + 排除文字“红色”；不是视觉颜色否定模型 |
| 7月微信图片或视频，不超过2MB | 日期、来源、大小取交集；图片与视频取并集 |
| 不少于1.5GB的视频 / 1到10MB的PDF / 图片不超过1.5MB | 包含边界的大小下限 / 区间 / 上限；支持 B、KB、MB、GB、TB，十进制字节，也支持 以内 / 以下 / 以上 |
| 大于10MB的PDF，不要合同 | PDF + 大小 + 文字排除 |
| 七月到八月的图片 / 11月至2月图片 | 所有年份的月份区间；后一例跨年 |
| 2025年12月至2026年2月图片 | 明确年份区间 |
| 电子表格 / 演示文稿 / 压缩包 / 代码 | 对应文件类型条件；支持图片、视频等类型之间的 或 / 和 / 顿号 |
| 横向的图片 / 标签为作品的图片 | 真实尺寸 / Finder 标签筛选；尺寸仍需要元数据 |
| P202601092289 / report.pdf | 字面检索；跳过向量生成 |
| 白色背景的微信图片 | 先保留来源和图片硬条件；剩余“白色背景”可进入已启用的本地语义搜索 |

普通搜索中识别出的条件显示为可移除标签。移除一个条件、切换类型、清空条件、改写输入均有回归覆盖。完整文件名、路径、引号、通配符和显式查询语法保留字面/高级查询语义。目录导航模式仍优先显示路径栏，不展示同一组条件标签；这一可见性差异记录为后续 UI 项目，本轮未扩大修改。

微信匹配依据仅是文件名或路径，不等于有客户端来源证明，也不代表接收时间。未写“拍摄”的月份仍明确使用修改时间；写了“拍摄”才读取拍摄元数据。类型优先识别短语尾部，避免把“应用设计文档”识别为应用。

## 未完整识别时

旧实现会因一个不支持的条件放弃整句解析。现在保留已识别的类型等条件，剩余部分按字面查询，并明确显示未完整理解提示；语义搜索不会绕过该提示返回近似结果。转换成可编辑查询后仍保留提示。

尚未支持：下载/接收/保存/创建时间、否定日期、复杂拍摄日期集合、任意嵌套布尔表达式与通用视觉否定。例如“昨天下载的图片”不会偷偷改用修改时间；“7月至8月拍摄的图片”不会只截取八月，或自动替换成修改日期。仍不能称为任意自然语言理解。

## 验证

- 全量 Debug：416 项，372 通过，44 按环境条件跳过，0 失败，81.358 秒。日志 `build/acceptance-natural35/final-regression.log`。
- 新增固定原生控制器组合场景：8 组查询 × 3 种查找方式 = 24 次；期望结果由合成文件的日期、路径、类型和大小独立指定。P95 9.10 ms，最大 9.77 ms，包括控制器搜索完成等待；样本很小，不代表真实大库端到端延迟。
- 500 次解析：P95 0.890 ms，最大 1.572 ms。没有同负载旧版对照，不计算提升倍数。
- 百万条合成内存索引：月份 + 类型并集 + 大小上限 + 来源路径并集 + 排除文字，8 次查询中位 20.48 ms，最大 27.91 ms，每次精确返回 66,667 条。当前核心源码以优化编译运行；不包含 UI、冷启动、磁盘读取或模型推理。日志 `build/acceptance-natural35/combined-benchmark.log`。
- 全文索引实测：正文含“微信”的其他目录文件、错误月份文件、正文含排除词文件均被排除，保留唯一符合条件的正文匹配文件。
- 日期边界、闰日、多时区、夏令时、大小边界、内容/语义硬条件、精确编号不启动向量、条件移除和提示保留均有断言。
- 新的解析行为改变了旧测试预期：JPG 现在生成格式标签；未知日期保留类型条件并警告。相应测试增加了标签、警告和不伪造拍摄条件的断言。
- 分发/身份检查通过。正式 Release 测试目标的旧 DEBUG 辅助接口编译问题未在此轮修改；此次全量通过指 Debug，不是 Release 测试套件。
