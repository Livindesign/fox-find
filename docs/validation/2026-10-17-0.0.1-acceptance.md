# Fox Find 0.0.1 本地验收 / Local acceptance

日期：2026-10-17。候选版本 **0.0.1 / build 27**。环境：Apple M1 Pro、16 GB、macOS 27.0.1、Swift 6.2.3。

**发布状态：未发布。** GitHub 仓库已转私有，`v0.8.6`、`v0.8.3-preview.1` 均撤回草稿，保留历史附件与标签。匿名仓库和更新清单请求均为 404。完整本地回归与维护者实际体验验收通过后，才考虑重新发布。公开仓库另行确认。

## 已确认的问题与修复

- 旧 build 26 实际进程 physical footprint 达 12.7 GB、峰值 13.2 GB。采样指向后台候选文件遍历：每个路径与每个内容目录比较时反复构建完整 `IndexConfig`，并在大批量循环中积累 Foundation 临时对象。该证据说明内存压力与卡顿，不能单凭它断言用户报告的闪退原因。
- 路径条件现在每轮预编译一次；每 256 项释放临时对象和索引读锁，每 32 项检查取消。保留路径边界、Unicode 等价与取消正确性。
- 输入、滚动、选择、预览及视图切换让内容索引暂停，空闲约 8 秒后恢复。已验证暂停期间不新增记录、空闲后继续完成。
- Quick Look 保持稳定选中项，合并快速连续选择；相同路径与相同文件版本不重载，文件大小或修改时间变化仍刷新。
- 内嵌预览布局直接设置最终结果区宽度，避免每次先放宽再缩窄；列表/宫格切换显式触发布局。

## 同场景前后对比

| 合成场景 | 修复前 | 修复后 |
| --- | ---: | ---: |
| 10 万候选文件、4 个不相交内容目录，后台扫描时间 | 12,745 ms | 284 ms |
| 同一轮候选遍历的额外峰值 physical footprint | 593.81 MiB | 0.016 MiB |

上述是同机、同脚本、Debug 微基准；耗时减少约 97.8%。不代表整个应用只使用这些内存，也不等于真实文件 OCR 或模型推理耗时。

## 最终回归实测

| 场景 | 结果 |
| --- | --- |
| 300 万条候选遍历 | 8.54 秒；采样未检测到额外峰值内存增长（不含预先构造索引的内存） |
| 后台遍历同时写索引锁，100 次 | P95 0.616 ms，最大 0.669 ms |
| 400 轮搜索、清空、列表/宫格、内嵌预览切换 | 全部通过；切换 P95 29.13 ms、最大 75.24 ms |
| 同轮交互搜索结果就绪 | P95 14.12 ms；使用 12 张合成图片文件名 |
| 400 轮交互预热后的进程内存 | 175.35 → 峰值 175.63 MiB，增长 0.28 MiB |
| Quick Look 窗口打开 | 211 ms；实拍窗口确认合成图片可见，非空白；窗口计时不等于首帧解码时间 |
| 12 张 4032×3024 JPEG 缩略图 | 首张 30.61 ms，全部 51.89 ms；缓存复用 0.62 ms |
| 30 万结果滚动，列表 / 宫格主线程处理 | P95 4.19 / 9.66 ms；本次各场景均无超过 25 ms 的滚动间隔 |
| 1,500 应用结果，列表 / 宫格 | P95 4.41 / 10.22 ms |

滚动指标不是屏幕 FPS；搜索基准不包含首次全盘索引、防抖、OCR、模型推理。早期分项运行曾出现一次 88.64 ms 列表处理异常值；后续两轮全量滚动未复现，保留原始记录而不从报告中抹去。

## 跳过与边界

- 全量运行的 5 个跳过：演示资料额外导出；公开 GitHub 包下载；实际签名包安装回退（打包后单独运行）；两个读取个人已有索引的可选基准。
- 另显式排除 2 个扫描宿主 Library/System 的测试，使用合成目录、30 万/300 万索引及磁盘映像覆盖，避免把个人文件作为回归资料。
- 仓库私有期间不验证公开 CDN 下载，也不把 404 当作成功下载；未发布新包。已单独确认匿名更新入口 404，客户端将其解释为暂无更新。
- 权限重启辅助进程完成测试，**未重置系统 TCC，也未重演真实首次授权点击**。
- 没有找到与本次用户报告时间对应的 build 26 崩溃栈；交互压力测试未复现闪退，不声称已证明全部崩溃原因。
- 原生预览测试出现一次 AppKit 内部 constraint-limit 警告，未影响显示和断言；保留日志继续观察。
- 本轮仅在上述 Mac 和系统验证；未验证其他硬件、较早 macOS、Intel、网络卷。无 Apple 公证。
- 0.8.x 到 0.0.1 是版本号重置，必须手动安装一次，自动更新继续禁止降级。

## English status

Version 0.0.1 build 27 is a local acceptance candidate. The repository is private;
previous releases are drafts. The final native/core/content suite ran 335 tests:
330 passed, five explicitly skipped, zero failures. Four hundred interaction cycles
and a three-million-entry candidate workload passed. The main fix removes repeated
path-configuration allocation and drains temporary objects during background scans.
Quick Look reloads and inline-preview layout are also coalesced.

Measurements are scoped local workloads, not universal responsiveness or crash-free
guarantees. Real first-run privacy consent, other Macs/macOS versions and public
release transport remain outside this run. Maintainer acceptance is required before
publication. Existing 0.8.x users need one manual install when version numbering resets.
