# Fox Find 0.8.5 build 19 — 原生界面验证

## 本轮交付

Swift / AppKit / SwiftUI 原生实现。主窗口使用 NSVisualEffectView，主搜索栏移除品牌图标；分类与常用文件夹使用产品面型 SVG，结果继续使用真实文件图标。保留用户已有强调色。

结果列表与网格使用单个 clip-layer 渐变遮罩；滚动条固定为覆盖式，不占用侧边空间。停止滚动 750 ms 后淡出，拖动滚动条时保持可见。未修改 macOS 的全局滚动条偏好。

引导以独立原生子窗口显示；屏幕空间不足时使用紧凑卡片。左右圆形按钮浏览说明，不写入任务完成状态。快捷键每页演示一次按压与回弹，插图轻移后停稳。没有永久动画循环；减少动态效果时移除位移。下拉菜单保留 NSMenu 行为，入口增加展开反馈，操作面板和预览增加短暂淡入。

内嵌预览合并快速选中操作；PDF 在后台加载后用 PDFKit 显示，其他文件使用 Quick Look。清空或改变选择会取消旧请求，防止旧文件重新出现。相关页使用「相关内容在第 X 页」「查看这一页」。

## 验证结果

- build 20 追加修正：统一蓝灰玻璃底色，三张引导插图改为真实 Alpha 透明素材，移除旧混合模式与渐变遮罩；原生深浅色截图确认不再有大块黑色背景。
- build 20 下拉箭头改为独立字形图层绕中心旋转，避免 AppKit 重排视图图层时偏移；查找方式菜单只显示选中勾号，移除三个重复放大镜。
- build 20 引导插图放大约 45%，放在说明文字与操作按钮之间的弹性区域居中；检查放大后的卡片仍保持 23 pt 左右留白。
- build 20 定向回归：41 项，40 通过、1 项性能测试因 CI 条件跳过，无失败。覆盖菜单开合/反向/窗口宽度变化后的箭头位置，菜单选中状态，插图透明角点及原有搜索行为。
- 插图居中调整后再次运行 FrostedInterfaceTests：9 项全部通过。最终 build 20 包签名与 ZIP 校验通过，安装后二进制与包内 SHA256 一致；实际原生引导窗口确认插图放大、居中、无黑底，展开的筛选箭头保持居中。
- 全量测试：298 项，269 通过，29 项因 CI/真实模型/真实设备条件跳过，无失败。
- 最后滚动条、布局和搜索稳定性回归：47 项通过，无失败。
- 追加验证：PDF 真正加载，以及清空选择后旧预览不能重新出现；窗口附着后保持覆盖式滚动条；持续滚动保持可见、停止后隐藏。
- 深浅色、中英文、列表、网格、空白页、三页引导及紧凑卡片：使用合成 PDF 索引生成原生截图并检查。
- 安装后实际原生窗口：检查主窗口、侧边引导、原始 Fox 图标、真实应用图标；通过引导箭头采集入场、按压和停稳三阶段画面，确认动效存在。
- 实机没有发送全局键盘或滚轮事件。滚动条的时序由原生控件回归覆盖；不能将截图或微基准等同于真实屏幕帧率。
- 实机 AXScrollBar 不提供 AXIncrement 操作，未将这一调用算作滚动验收成功。
- 原生 App、helper 签名严格校验，ZIP 完整性、许可文件、资源包均检查；源目录分发检查及独立应用身份检查通过。

## 性能记录

固定 900×600 窗口、100 个合成结果、100 个计时样本。单位 ms，测量 AppKit 更新与绘制处理，不是屏幕端到端 FPS。新旧行高不同，不能据此声称等量绘制性能提升。

| 场景 | 修改前 P95 | 最后一次 UI 回归 P95 |
| --- | ---: | ---: |
| 列表，无引导 | 3.218 | 5.060 |
| 列表，有引导 | 3.085 | 1.537 |
| 网格，无引导 | 4.836 | 1.451 |
| 网格，有引导 | 4.681 | 1.305 |

每项均低于测试阈值 16.7 ms；列表无引导本次比基线慢，未宣传性能提升。此前同场景多次运行约 1.6–2.2 ms，存在测量波动。所有四组内容补充稳定性场景：0/40 空结果采样、0 次网格重复重载；100 次引导状态更新未改变选中项或滚动位置。
